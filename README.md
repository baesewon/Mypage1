# FreshKeeper - 유통기한 관리 웹앱 🥑

집에 있는 식품의 유통기한을 간편하게 등록하고 똑똑하게 관리할 수 있는 모바일 퍼스트 반응형 웹 애플리케이션입니다.

---

## 🌟 주요 기능

### 1단계: 기본 기능
- **식품 등록 / 수정 / 삭제**: 식품명, 유통기한, 수량(단위 포함), 보관 위치(냉장고, 냉동실, 실온, 기타), 메모.
- **D-day 자동 계산 및 시각화**:
  - `D+2 (유통기한 지남)`: 붉은색 경고
  - `D-day (오늘 만료)`: 주황색 긴급 알림
  - `D-3`: 1~3일 이내 임박 알림
  - `D-7`: 4~7일 이내 주의 알림
  - `D-14`: 안전 보관 녹색 배지

### 2단계: 식품 관리 편의 기능
- **식품 사진 첨부**: 파일 업로드 / 카메라 촬영 사진을 HTML Canvas로 자동 압축(300x300)하여 LocalStorage에 최적화 저장. 사진 미등록 시 카테고리별 일러스트 자동 표시.
- **9대 카테고리**: 과자, 음료, 우유/유제품, 육류, 채소, 과일, 냉동식품, 조미료, 기타.
- **실시간 검색**: 식품명, 카테고리, 메모 실시간 검색.
- **다양한 필터링**: 전체, ⚠️ 유통기한 임박, 🚨 유통기한 지남, ❄️ 냉장고, 🧊 냉동실, 🌡️ 실온.
- **유연한 정렬**: 유통기한 가까운 순, 유통기한 먼 순, 이름순.

### 3단계: 알림 기능
- **다단계 알림 기준**: 7일 전, 3일 전, 1일 전, 유통기한 당일, 유통기한 초과.
- **홈 화면 상단 '⚠️ 유통기한 임박 식품' 전용 위젯**.
- **브라우저 푸시 알림 (Web Notification API)** 및 브라우저 알림 미지원 환경에서도 동작하는 **인앱 알림 센터 (종 모양 배지 + 팝업 알림)**.

### 4단계: 대시보드와 통계
- **홈 대시보드 현황판**:
  - 전체 식품 수, 7일 이내 임박 수, 오늘 만료 수, 유통기한 지난 식품 수, 보관 위치별 수량.
- **통계 화면**:
  - 현재 보관 중인 식품 수
  - 총 등록한 식품 수
  - 알뜰 소진(식사/사용) 수
  - 유통기한 지나 폐기/삭제한 식품 수 (삭제 시 소진 vs 폐기 선택으로 정확한 지표 반영)
  - 소진율 vs 폐기율 시각적 프로그레스 바
  - 보관 장소별 / 카테고리별 분포 현황

### 5단계: 모바일 퍼스트 반응형 UI
- 직관적인 하단 6대 내비게이션 바 (홈, 목록, 추가, 임박, 통계, 설정).
- PC와 모바일 모두에 최적화된 반응형 프레임 레이아웃.
- 브라우저 LocalStorage 영속화로 새로고침 후에도 안전하게 유지.
- 설정 탭에서 **12종 한국 식재료 샘플 데이터 원클릭 채우기**, **JSON 백업/복원**, **데이터 초기화** 지원.

### 6단계: AI 챗봇 (FreshKeeper AI 셰프 🥑)
- **우하단 플로팅 원형 버튼**: 클릭 시 부드럽게 대화창 토글.
- **OpenAI ChatGPT API 연동**: 지정 모델 `gpt-5-mini` 기반 실시간 대화.
- **순차적 말풍선 UI**: 사용자와 AI의 메시지를 시간순으로 정렬 표시, 타이핑 애니메이션 및 마크다운 지원.
- **스마트 식재료 인식**: 현재 앱에 보관 중인 식재료 및 임박 식품을 자동으로 파악하여 맞춤형 요리 레시피 및 보관 팁 제공.
- **손쉬운 API 키 설정**: `js/chatbot.js` 파일 상단 변수(`OPENAI_API_KEY`)에 직접 입력하거나 대화창 상단 🔑 버튼으로 브라우저에 간편 등록 가능.

## 🚀 실행 방법

### 방법 1: 웹 서버로 실행 (권장)
본 프로젝트 폴더에서 Python 내장 웹 서버를 실행합니다:
```bash
cd C:\Users\Administrator\.gemini\antigravity\scratch\food-expiry-app
python -m http.server 8080
```
웹 브라우저(Chrome, Edge, Safari 등)에서 아래 주소로 접속합니다:
👉 **http://localhost:8080**

### 방법 2: 브라우저에서 직접 열기
`index.html` 파일을 브라우저로 더블 클릭하거나 드래그 앤 드롭하여 바로 실행할 수도 있습니다.
(단, 브라우저 알림 및 ES 모듈 로딩을 위해 로컬 웹 서버 실행을 권장합니다.)

├── index.html               # 메인 SPA 마크업 및 모달 구조
